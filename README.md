# Irfan Nazmi · The Thinking Pond

An interactive portfolio with a living pond, floating chessboard and four project stories.

[View the portfolio](https://ipannajmii.github.io/portfolio/)

## Projects

- REGISSION — full-stack AI and IoT chess system; Best Project Award, C2PI 2026.
- Advanced Python-Based Digital Forensic Log Analysis Tool.
- MediaPipe Face & Hand Tracking using Python.
- Smart IoT Blind Stick — academic assistive technology concept.

## Explore

Scroll for slide-in sections, filter the projects, choose a chess piece, explore the REGISSION stages, or open a project gallery. Select an image to enlarge it. The galleries have thumbnails, Previous/Next controls, keyboard navigation and touch swiping. A motion control pauses the pond and section effects; system reduced-motion preferences are respected.

## Getting started

Open `index.html` in a browser. This is a buildless site; no packages, accounts or terminal commands are required.

- [GitHub upload steps](START-HERE.md)
- [Add your own photos](ADD-YOUR-PHOTOS.md)

The galleries initially show original, labelled concept/workflow illustrations. They are not photographs or screenshots of the actual projects. Add real photos and captions in `project-data.js`.

The latest user-supplied CV is included unchanged at `assets/irfan-nazmi-cv.pdf`. LinkedIn and GitHub links are in the contact section.

## Design

Original pond and chess theme retained from the previous portfolio. Scroll and slide motion were informed by the user’s reference, [RIZQ Technologies](https://rizqtech.com.my/). The site uses local HTML, CSS, JavaScript, SVG illustrations and a WebGL/Canvas water renderer, with a still background fallback.
